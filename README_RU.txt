ФОТОКАТАЛОГ — АРХИВ ПРЕЗИДЕНТА КЫРГЫЗСКОЙ РЕСПУБЛИКИ
Обновлённая версия для репозитория Katalog_5

Основные изменения:
- отдельная база Katalog_5, не пересекается с Katalog_3;
- прогресс импорта с процентом, количеством обработанных записей и статистикой;
- ускоренный пакетный импорт Microsoft Access для больших баз (25 000+ записей);
- пакетные транзакции SQLite и индекс по архивному номеру;
- каталог показывает по 100/200/500 строк на странице, чтобы не создавать десятки тысяч миниатюр сразу;
- сквозной столбец № в окнах просмотра, редактирования и каталога;
- импорт Word DOCX прямо из Каталога;
- массовая вставка таблицы из Word/Excel через буфер обмена;
- импорт фотографий по имени файла/архивному номеру прямо из Каталога;
- прогресс индексации лиц;
- белые/светло-серые чередующиеся строки, усиленные заголовки таблиц;
- кнопки немного темнее фона;
- Настройки программы в окне Редактирование: дневной/ночной режим, цвет фона, кнопок и выделения;
- кнопка печати на первом окне: текущая карточка или все результаты поиска через предпросмотр в браузере;
- увеличенное поле описания на первом окне, шрифт Arial;
- множественный выбор в Каталоге Shift/Ctrl, галочки, Delete;
- заставка с флагом и гербом, встроенными в EXE.
