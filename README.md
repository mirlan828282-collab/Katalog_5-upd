# PhotoArchiveCatalog — Katalog_5 updated

Windows photo archive catalog for the Archive of the President of the Kyrgyz Republic.

This version adds fast batched Access import, progress indicators, catalog pagination, numbering, Word/clipboard imports, photo matching by archive number, theme settings, printing, multi-selection/deletion, and a separate Katalog_5 data folder.

Default protected-section password: `12345`.

Build the Windows EXE with the included GitHub Actions workflow.
